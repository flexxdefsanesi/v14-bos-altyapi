# 🤖 Boş Altyapı

DJS V14 ile kodlanmış boş bot altyapısı.

Botun kurulumuna ve anlatımına [YouTube](https://youtube.com/@AyranCodeShare) kanalımızdan ulaşabilirsiniz.

## ✨ Özellikler

- 📈 Örnek kaliteli komutlar
- 💨 Hızlı, kolay kullanım ve kurulum
- 🤖 DJS V14

## ⚙️ Kurulum

1. Bu projeyi klonlayın veya indirin.

    ```bash
    git clone https://github.com/clydeofficial/v14-bos-altyapi.git
    ```

2. Proje klasöründe cmd'yi aktifleştirin.

3. Gerekli bağımlılıkları yükleyin:

    ```bash
    npm install
    ```

4. `config.json` dosyasını kendinize göre düzenelyin.

5. Botu başlatın:

    ```bash
    npm start
    ```

## 💡 Kullanım

1. Botunuz Discord sunucunuza gerekli yetkililerle ekleyin,
2. Botu aktif edin,
3. "/ping" yazarak ilk komutu kullanın.
